# Syncora AI (prototype)

*One community. Shared resources. Unlimited possibilities.* · RTC NEXUS

A single-file, no-dependency prototype that matches community needs (schools, libraries) with offers (equipment, volunteers) using demo data. AI recommends, a person approves.

**Live demo:** `https://<your-username>.github.io/<repo-name>/`

## Match score
40% need fit + 25% proximity + 20% urgency and impact + 15% availability and condition.

## Run locally
Open `index.html` in a browser. No build step.

## Deploy
Pushing to `main` publishes the site via GitHub Pages (see `.github/workflows/pages.yml`).
In the repo: **Settings → Pages → Source: GitHub Actions**.

## Notes
- All listings live in the page's memory only and reset on reload.
- The map is schematic; the data is demo data.
